# Job API - Spring Boot Backend

A beginner-friendly backend REST API project built using Spring Boot.  
This project simulates a Job Management System and demonstrates backend architecture concepts such as layered design, REST APIs, and CRUD operations.

---

## Features

- Add Job
- View All Jobs
- Search Job By ID
- Search Job By Name
- Update Existing Job
- Delete Job

---

## Technologies Used

- Java
- Spring Boot
- REST API
- ArrayList (In-Memory Storage)
- Maven

---
